# BloxCEO Game Idea Randomiser

Stuck on what to build? Roll a game idea.

**How to use it**

1. Roll a d10 (or pick a random number 1 to 10) for each table below. No dice? Use a random number generator.
2. Write down the four results.
3. Paste the "Prompt for your AI" at the bottom into ChatGPT or Claude, filling in your results.

## Prompt for your AI

```
I'm building a Roblox game in Roblox Studio and I have no coding experience.

Genre: [your genre]
Setting: [your setting]
Hook: [your hook]
Monetisation: [your monetisation idea]

1. Turn this into a one-paragraph game concept.
2. List the 5 core features I need for a first playable version.
3. For feature 1, give me the Luau script, tell me exactly where to put it
   in Roblox Studio, and how to test it.
```

Build one feature at a time. When something breaks, paste the error back into your AI and ask it to fix it.
